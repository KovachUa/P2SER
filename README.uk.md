# P2SER - Децентралізований P2P Оркестратор Контейнерів

P2SER (Peer-to-Peer Service Edge Runtime) — це легковаговий, децентралізований (Masterless) оркестратор контейнерів, розроблений спеціально для Edge та IoT середовищ (Raspberry Pi, Orange Pi та інших одноплатних комп'ютерів).

На відміну від важких систем на кшталт Kubernetes, P2SER нативно розуміє ваш стандартний `docker-compose.yaml`. Вам не потрібно писати сотні рядків складних YAML-маніфестів.

## 🚀 Ключові можливості

*   **P2P Архітектура (Masterless):** Відсутні виділені керуючі вузли (master nodes). Усі вузли рівні, а стан кластера синхронізується за допомогою алгоритму консенсусу Raft та Gossip протоколу.
*   **Нативна підтримка Docker Compose:** Повна сумісність із синтаксисом Docker Compose. Розгортайте програми використовуючи файли, які у вас вже є.
*   **Оптимізація для Edge & IoT:** Написано на Go, працює напряму з `containerd` (минаючи Docker daemon) для максимальної продуктивності та мінімального споживання пам'яті на ARM64 та x86.
*   **Гарячий резерв (Warm Standby):** Кастомні розширення (`x-p2ser`) дозволяють конфігурувати "сплячі" репліки, які миттєво переймають трафік при падінні основного сервера, економлячи ресурси у звичайний час.
*   **Zero-Touch розгортання:** Ініціалізація кластера одним токеном (`p2ser init`). Вузли автоматично знаходять один одного через mDNS/UDP в локальній мережі.
*   **Вбудований Web-Дашборд:** Містить красивий React UI (схожий на панелі хмарних провайдерів) для керування проєктами, розгортання шаблонів та моніторингу метрик.
*   **Сучасна мережа:** Вбудований IPAM, інтеграція з CNI та VXLAN оверлейні мережі для зв'язку між Pod-ами на різних фізичних машинах.
*   **Zero Trust Безпека:** mTLS шифрування трафіку, зашифрована база стану (`bbolt`), Rootless контейнери, eBPF, а також вбудований Geo-IP фільтр.

## 📦 Як описати сервіс

P2SER зберігає повну сумісність зі стандартом Compose. Для конфігурації унікальних фіч кластера ми використовуємо офіційні поля розширень (починаються з `x-`).

### Приклад: Гарячий резерв (Warm Standby)
Запуск двох активних реплік та однієї "сплячої", яка увімкнеться у разі збою:

```yaml
services:
  frontend:
    image: nginx:latest
    ports:
      - "80:80"
    deploy:
      replicas: 2
    x-p2ser:
      standby_replicas: 1
```

## 🛠 Встановлення та Bootstrap

1. **Ініціалізація кластера (Перший вузол):**
   ```bash
   p2ser init 'MY_SECRET_TOKEN'
   ```
2. **Приєднання до кластера (Інші вузли):**
   Просто виконайте цю ж команду на інших машинах в локальній мережі. Вони автоматично знайдуть лідера.
   ```bash
   p2ser init 'MY_SECRET_TOKEN'
   ```
3. **Розгортання застосунку:**
   ```bash
   p2ser deploy -f ./docker-compose.yaml
   ```

## 🖥 Веб-Інтерфейс та API

P2SER має відокремлений веб-дашборд (React + Vite), що працює через REST API:
*   **Візуальне керування:** Деплой додатків з маркетплейсу шаблонів або власних Git-репозиторіїв.
*   **Моніторинг:** Графіки CPU/RAM в реальному часі.
*   **Веб-термінал:** Bash-консоль в один клік прямо у браузері.
*   **Ізоляція проєктів:** Групування ресурсів у "Проєкти" (Namespaces) зі своїми квотами та лімітами.

## 🛡 Архітектура та Безпека

*   **Raft + Bbolt:** 100% дублювання журналу транзакцій на всі вузли кластера.
*   **Розподілене блокування:** Захист від конфліктів через Compare-and-Swap (CAS) та Оренду (Leases).
*   **Самозцілення (Reconciliation):** Безперервний цикл узгодження стану. Якщо вузол падає — задачі миттєво перезапускаються на інших серверах.
